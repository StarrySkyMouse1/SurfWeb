DESIGN TOKENS

色板

  • 纸面 #f3f1eb
  • 墨黑 #121212
  • 强调 #3d5afe（可换品牌色）

字体

  • Silkscreen — 导航、#名次、Tier、区块代号
  • IBM Plex Sans / 系统中文 — 玩家名、说明
  • JetBrains Mono — 时间、连接串、地图名

像素语法（克制使用）

  • 边框统一 2px，阴影仅 2px/4px 阶梯，不用模糊阴影
  • 背景 8×8 淡网格（可选关）
  • hover 行：反色填黑，与方向 C 一致
  • 按钮按下：阴影消减 + 位移 2px

与 v1 方向 C 差异

  • 保留：黑白对比、表格式、信息密度
  • 新增：纸色底、像素标签、阶梯阴影、小尺寸 logo 块
  • 去掉：纯黑白冷感 → 略暖纸色；导航英文短码 HOME/MAPS/SRV

确认此方向后回复「采用像素简约」→ 再写入 spec 并改 Tailwind 主题。
