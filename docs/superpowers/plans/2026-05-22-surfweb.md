# SurfWeb 实施计划

> **给自动化协作者：** 须配合 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐步执行。步骤使用复选框（`- [ ]` / `- [x]`）跟踪进度。

**目标：** 搭建对标 KSF 的滑翔记录站：.NET 8 只读 API 连接 Shavit MySQL，前端 Vue 3 + Tailwind（UI 方向 C）。

**架构：** 后端调整为强特征 DDD + CQRS：`Api` 适配层，`Application` 分 Commands / Queries，`Domain` 放聚合根/值对象/领域事件，`Infrastructure` 分读写实现；Vite 单页应用继续调用 `/api/v1`。

**技术栈：** .NET 8、EF Core + Pomelo MySQL、Vue 3、TypeScript、Vite、Tailwind CSS 4、Vue Router 4

**设计文档：** `doc/design.md`（改代码须同轮同步，见 `.cursor/rules/design-sync.mdc`）
